# 🤖 Agent Skills

給 AI 助手使用的技能庫，支援 Claude Code、Gemini CLI、OpenClaw 等。

## 技能列表

| 技能 | 說明 |
|------|------|
| [github-pages-deploy](./github-pages-deploy/) | 部署純前端專案到 GitHub Pages |

## 使用方式

### Claude Code
```bash
# 複製到個人技能目錄
cp -r github-pages-deploy ~/.claude/skills/
```

### Gemini CLI / 其他 Agent
將 `SKILL.md` 內容提供給 Agent，或放到對應的指令目錄。
